## 关键设计决策

| 决策 | 选择 | 否决项 | 理由 |
|------|------|--------|------|
| seq 溢出阈值 | 2^24 (16,777,216) | 2^24.5 (浮点) | 整数比较零开销 |
| seq 溢出行为 | encrypt/decrypt 返回失败 | 异常/abort | Transport 层检测后触发重连 |
| ISN 降级 | RAND_bytes 失败返回 0 | 保留 fallback | 低熵 ISN 有安全风险 |
| TlsHotState 布局 | 4 cache lines (key/iv + seq) × 2 | 2 cache lines | 消除 TX/RX 伪共享 |
| recv len 类型 | callback 参数改 size_t | 改内部 RxMessage | 最小变更 |
| record.hpp 拆分 | 3 文件 + 聚合头 | 2 文件 | SystemStats 独立职责 |
| transport.hpp 拆分 | 推迟 | 3 文件 | 私有成员依赖复杂 |
| reorder buffer | 模板参数 `TcpSession<ReorderSlots=8>` | 运行时参数 | 零运行时开销 |
| connector 重载 | 返回 `unique_ptr<Transport>` | 返回 ConnectResult | Platform 非新建，不应 move |
