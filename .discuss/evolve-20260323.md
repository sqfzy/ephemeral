## Project Profile

**Name**: ephemeral (eph) — C++23 header-only ultra-low-latency network library
**Target Users**: Algorithmic trading / financial market connectivity
**Core Capabilities**:
  - Dual TCP backends: POSIX sockets + DPDK user-space stack
  - TLS 1.3 with direct AEAD bypass (~150ns savings per record)
  - WebSocket RFC 6455, FIX, ITCH 5.0 protocol framers
  - SPSC lock-free queues, TSC timing, HdrHistogram
  - Cache-line aligned structures, concept-based polymorphism

**Architecture**: 5 layered modules (eph-base -> eph-utils -> eph-containers -> eph-net -> eph-dpdk) + eph-itch, eph-fix
**Maturity**: Functionally rich, approaching production-ready
**Test Coverage**: 132+ tests, benchmarks for critical hot paths
