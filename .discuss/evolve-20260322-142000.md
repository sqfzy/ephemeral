## 项目画像

**定位**：C++23 header-only 超低延迟 WebSocket (WSS) 通信库，支持 POSIX socket 和 DPDK kernel-bypass 双后端

**核心能力**：
- TLS 1.3 加密 WebSocket 通信（TCP → TLS handshake → WS Upgrade → AEAD 数据平面）
- 零拷贝 SPSC 无锁队列（BoundedQueue、EvictingQueue，含 bytes 变体）
- DPDK 内核旁路路径（用户态 TCP + ARP + 网络包构建）
- 自动重连（指数退避 + 抖动）
- RFC 6455 合规（UTF-8 校验、close code 验证、masking、fragmentation 重组）

**架构概要**：eph-base → eph-utils → eph-containers → eph-net → eph-dpdk，分层 header-only

**当前成熟度**：功能基本可用

**已有测试覆盖**：22 个测试文件
