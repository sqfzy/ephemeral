## Implementation Record

### Gap 1: EvictingQueue<T,1> size_approx() and empty()
- **Requirement**: Primary template has size_approx()/empty() but Capacity=1 specialization doesn't. EvictingQueueBytes calls these on its inner queue, so Capacity=1 would fail to compile.
- **Solution**: Added size_approx() (returns 0 or 1 based on seq state) and empty() to the specialization.
- **Changes**: `eph-containers/include/eph/containers/evicting_queue.hpp`
- **Tests**: 4 new tests (SizeApproxStartsAtZero, SizeApproxReflectsUnread, SizeApproxAfterClear, SizeApproxAfterMultipleOverwrites)

### Gap 2: ConnectionErrorInfo::to_json()
- **Requirement**: All other public types have to_json() — TransportStats, TransportConfig, ConnectionInfo, RttStats.
- **Solution**: Added to_json() producing `{"code":"...","detail":"...","http_status":N}` with RFC 8259 escaping.
- **Changes**: `eph-net/include/eph/net/transport_types.hpp`
- **Tests**: 2 new tests (ToJsonProducesValidJson, ToJsonEscapesDetail)

### Gap 3: std::formatter<ConnectionInfo>
- **Requirement**: All other public types have std::formatter specializations.
- **Solution**: Added formatter producing `remote_ip:port tls=version (cipher) subproto=name`.
- **Changes**: `eph-net/include/eph/net/transport_types.hpp`
- **Tests**: 2 new tests (FormatsWithAllFields, FormatsWithEmptyFields)

### Gap 4: RttStats convenience accessors
- **Requirement**: p50_us/p99_us/mean_us exist but min_us/max_us/p999_us don't. dump() manually computes these.
- **Solution**: Added min_us(), max_us(), p999_us() and updated dump() to use them.
- **Changes**: `eph-net/include/eph/net/transport_types.hpp`
- **Tests**: 1 new test (AllConvenienceAccessors)
