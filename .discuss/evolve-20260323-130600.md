## Project Profile

**Position**: Ultra-low-latency C++23 header-only WebSocket/TLS networking library for HFT
**Core capabilities**:
  - Dual-backend transport (POSIX socket + DPDK user-space TCP)
  - Lock-free SPSC queues (bounded blocking + evicting wait-free)
  - Custom TLS 1.3 data plane (EVP_AEAD bypassing SSL_write/SSL_read)
  - Pluggable message framers (WebSocket, ITCH, FIX, raw, length-prefix)
  - HDR histogram-based latency recording with RTT measurement
**Architecture**: 6 layered headeronly modules (utils → containers → net → itch/fix/dpdk) with concept-based zero-cost abstractions
**Current maturity**: Feature-complete, approaching production readiness
**Test coverage**: 1,207 tests across all modules (1,185 before evolve)
