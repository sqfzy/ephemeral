## 项目画像

**定位**：Ultra-low-latency C++23 header-only library for WebSocket + TLS 1.3 network communication with DPDK kernel-bypass and POSIX socket backends, targeting financial trading/market data.

**核心能力**：
- Pluggable TCP transport (POSIX socket / DPDK user-space) via C++20 concepts
- TLS 1.3 data-plane with direct EVP_AEAD (bypassing SSL_write/read)
- Lock-free SPSC queues (BoundedQueue, EvictingQueue) with cache-line isolation
- WebSocket RFC 6455 framing + pluggable MessageFramer concept
- ITCH 5.0 and FIX protocol parsers (zero-copy)
- CPU pinning, TSC timestamping, HdrHistogram

**架构概要**：Layered pipeline — eph-utils → eph-containers → eph-net → eph-dpdk, with eph-itch/eph-fix as protocol extensions

**当前成熟度**：接近生产就绪

**已有测试覆盖**：28 test files, 1,260+ tests; comprehensive coverage of all modules
