## Project Profile

**Position**: C++23 header-only ultra-low-latency WebSocket/TLS transport library for HFT
**Core capabilities**:
  - Dual TCP backends (POSIX socket / DPDK kernel-bypass) via compile-time concepts
  - TLS 1.3 with data-plane AEAD (aws-lc), ~164ns TX latency on DPDK
  - RFC 6455 WebSocket with zero-copy framing
  - SPSC lock-free queues (bounded + evicting) with cache-line alignment
  - HdrHistogram + Recorder/ConcurrentRecorder for latency measurement
  - FIX 4.4 zero-copy parser/builder, NASDAQ ITCH 5.0 parser
  - Pluggable MessageFramer concept (WS, FIX, ITCH, length-prefix, raw)
**Architecture**: eph-utils -> eph-containers -> eph-net -> (eph-dpdk, eph-itch, eph-fix)
**Maturity**: Feature-complete, approaching production-ready
**Test coverage**: 1,740 tests across 34 binaries, 14+ benchmarks, 7 examples
