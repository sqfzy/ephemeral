## Project Profile

**Position**: Ultra-low-latency WebSocket over TLS C++23 header-only library for datacenter environments
**Core capabilities**:
  - Zero-cost TCP backend abstraction (POSIX socket / DPDK user-space TCP)
  - TLS 1.3 encryption/decryption (aws-lc)
  - WebSocket / ITCH / FIX protocol codec
  - Lock-free SPSC queues (BoundedQueue / EvictingQueue)
  - High-precision latency measurement (TSC + HdrHistogram + Recorder)
**Architecture**: eph-utils -> eph-containers -> eph-net -> eph-itch/eph-fix, eph-dpdk sidecar
**Maturity before**: Functionally usable, approaching production readiness
**Test coverage before**: Good for containers/net/dpdk/itch/fix, but SystemStats and Recorder had zero test coverage
