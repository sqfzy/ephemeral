## Implementation Record

### Gap 1: FIX BodyLength validation (kMaxBodyLength)
- **Requirement**: Prevent memory exhaustion from malformed FIX messages with absurdly large BodyLength
- **Solution**: Added `kMaxBodyLength = 1MB` constant in parser.hpp, validated inside digit-parsing loop (prevents integer overflow)
- **Changes**: framer.hpp, parser.hpp
- **Tests**: 6 new (oversized, at-limit, overflow, constant check)
- **Commit**: 3def110, 9cbcc74

### Gap 2: ITCH auto-trimmed stock symbol accessors
- **Requirement**: Eliminate bug-prone manual trimming of right-padded ITCH stock fields
- **Solution**: Added `stock_trimmed()` to all 13 message-type namespaces, `attribution_trimmed()` for AddOrderMPID
- **Changes**: messages.hpp (+70 lines)
- **Tests**: 7 new (multiple message types, edge cases)
- **Commit**: 3def110

### Gap 3: ITCH parser error offset reporting
- **Requirement**: Enable debugging of corrupted ITCH feeds
- **Solution**: Enhanced `ParserStats` with `first_error_offset`, `first_error_type`, `first_error_msg_byte`; added DEBUG-level logging in parse_all
- **Changes**: parser.hpp
- **Tests**: 4 new (unknown type, truncated, no-error, reset)
- **Commit**: 3def110
