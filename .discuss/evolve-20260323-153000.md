## 项目画像

**定位**：Ultra-low-latency C++23 header-only WebSocket/TLS/TCP library for financial market data (NASDAQ ITCH, FIX) over POSIX sockets or DPDK kernel-bypass networking.

**核心能力**：
- Zero-copy SPSC queues (BoundedQueue, EvictingQueue)
- TLS 1.3 AEAD encryption (AES-256-GCM via aws-lc)
- WebSocket RFC 6455 framing with batch CSPRNG masking
- ITCH 5.0 / FIX 4.4 zero-copy parsers
- DPDK user-space TCP stack (~164ns E2E TX, ~139ns E2E RX)
- Pluggable framer concept (WsFramer, RawFramer, LengthPrefixFramer)

**架构概要**：6 header-only modules (utils → containers → net → itch/fix, dpdk) with concept-based compile-time polymorphism

**当前成熟度**：功能基本可用 → 接近生产就绪

**已有测试覆盖**：500+ tests across all modules; benchmarks for latency-critical paths
