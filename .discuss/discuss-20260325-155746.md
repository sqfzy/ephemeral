## 最终方案

### 核心决策
bool EnableTimestamps 模板开关 + TransportConfig on_tx_measured 回调 + RxMessage 自带 arrival_tsc + last_arrival_tsc() accessor。

### 方案细节
- TxMessage/RxMessage 用 [[no_unique_address]] TsPolicy 控制 tsc 字段
- TX：enqueue 写 enqueue_tsc，TX loop per-message 调 on_tx_measured(enqueue, flush, opcode)
- RX：rx_loop 写 current_arrival_tsc_，rx_enqueue 写 RxMessage.ts.tsc
- Pull 模式：用户从 RxMessage 读 arrival_tsc
- Push 模式：用户在 on_message 回调中调 last_arrival_tsc()
- EnableTimestamps=false：全路径 if constexpr 消除，消息无 tsc 字段

### 已解决的分歧
- pong pipeline 归入 RTT
- on_message 签名不变，用 accessor
- std::function 开销可接受
