## Implementation Record

### Gap 1: JSON String Escaping (Tier 1)
- **Need**: `to_json()` methods interpolated strings without escaping, producing malformed JSON when fields contain `"`, `\`, or control characters
- **Solution**: Added `detail::json_escape()` implementing RFC 8259 §7 with fast-path bypass for strings without special chars. Applied to all string fields in `TransportConfig::to_json()` and `TransportStats::to_json()`
- **Files**: `eph-net/include/eph/net/transport_types.hpp`
- **Tests**: 8 new tests (plain string, empty, quotes, backslashes, control chars, unicode escapes, UTF-8 passthrough, config integration)

### Gap 2: RTT Stats Integration (Tier 2)
- **Need**: RTT stats only accessible via separate `rtt_stats()` call; `stats()` and its JSON output didn't include RTT data
- **Solution**: Added `RttStats rtt` field to `TransportStats`, populated from `rtt_stats()` in `Transport::stats()`. Updated `dump()` and `to_json()` to include RTT data
- **Files**: `eph-net/include/eph/net/transport_types.hpp`, `eph-net/include/eph/net/transport.hpp`
- **Tests**: 3 new tests (JSON includes RTT object, dump includes RTT line, stats RTT integration)

### Gap 3: RttStats::to_json() (Tier 2)
- **Need**: RttStats had `dump()` but no `to_json()`, asymmetric with TransportStats/TransportConfig
- **Solution**: Added `to_json()` method outputting all fields (count, min/max/mean_ns, percentiles in both ns and us)
- **Files**: `eph-net/include/eph/net/transport_types.hpp`
- **Tests**: 2 new tests (empty stats, populated stats with all fields)

### Gap 4: Benchmark Deprecation Fix (Tier 3)
- **Need**: `benchmark::internal::Benchmark*` deprecated in Google Benchmark 1.9.x
- **Solution**: Changed to `::benchmark::Benchmark*`
- **Files**: `benchmarks/net/bench_transport_pipeline.cpp`, `benchmarks/containers/bench_bq_batch.cpp`
