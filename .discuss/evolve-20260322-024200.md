## Project Profile

**Position**: Header-only C++23 ultra-low-latency WebSocket (WSS) library with DPDK support
**Core capabilities**:
  - Lock-free SPSC queues (bounded + evicting)
  - TLS 1.3 session management + AEAD encryption/decryption
  - RFC 6455 WebSocket framing (fragmentation, masking, close handshake)
  - Generic Transport orchestrator (TCP -> TLS -> WS with auto-reconnect)
  - DPDK userspace TCP state machine
  - TSC nanosecond timing, hugepage allocation, CPU affinity
**Architecture**: 5 modules (base -> utils -> containers -> net -> dpdk)
**Previous maturity**: Functionally mostly complete
**Test coverage**: 17 test files, 126+ unit tests
