## Project Profile

**Positioning**: Ultra-low-latency C++23 WebSocket over TLS 1.3 library for datacenter/exchange feed applications
**Core capabilities**:
  - Lock-free SPSC queues (BoundedQueue, EvictingQueue, byte variants)
  - POSIX Socket and DPDK TCP backends via TcpTransport concept
  - TLS 1.3 hot-path AEAD bypass (aws-lc)
  - RFC 6455 WebSocket framing with masking, ping/pong, close, fragmentation
  - Generic Transport<> with auto-reconnect, exponential backoff, CPU pinning
  - TSC nanosecond timing, hugepage allocation, CPU topology
**Architecture**: 5-layer modules (base -> utils -> containers -> net -> dpdk), header-only, zero-overhead templates
**Maturity before**: Functional, core data path complete
**Test coverage**: 17 test files, 126+ cases. Transport orchestration layer untested.

## Implementation Record

### Gap 1: WebSocket Close Handshake Race Fix
- **Requirement**: Server Close frame must receive a Close response per RFC 6455 section 5.5.1
- **Solution**: Introduced `closing_` atomic flag. RX sets it on server Close (instead of `running_=false`). TX drains queue (including Close response) then sets `running_=false`. RX spins on `closing_` without reading socket.
- **Changes**: `eph-net/include/eph/net/transport.hpp`
- **Tests**: Build-verified (template instantiation in socket_wss_client)
- **Commit**: `5cce249`

### Gap 2: Transport Queue Occupancy API
- **Requirement**: Users need to detect backpressure before send() returns -EAGAIN
- **Solution**: Added `tx_queue_size()`, `rx_queue_size()`, `tx_queue_fill_ratio()`, `rx_queue_fill_ratio()` forwarding BoundedQueue::size()
- **Changes**: `eph-net/include/eph/net/transport.hpp`
- **Tests**: Build-verified
- **Commit**: `4c15e68`

### Gap 3: Blocking wait_recv() API
- **Requirement**: Socket backend users need blocking receive without busy-polling
- **Solution**: Added `wait_recv(callback, timeout)` with two overloads (with/without opcode). Uses `std::this_thread::yield()` between polls for sub-ms latency without 100% CPU.
- **Changes**: `eph-net/include/eph/net/transport.hpp`
- **Tests**: Build-verified
- **Commit**: `d993026`

### Gap 4: Socket WSS Client Example
- **Requirement**: Non-DPDK users have no way to get started with the library
- **Solution**: Created `examples/socket_wss_client.cpp` showing TCP factory pattern, transport creation, send_text/wait_recv loop, graceful shutdown, and stats dump. Updated xmake.lua with `net_examples` table.
- **Changes**: `examples/socket_wss_client.cpp` (new), `xmake.lua`
- **Tests**: Build-verified
- **Commit**: `244d0f2`
