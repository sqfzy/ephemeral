## 项目画像

**定位**：高性能 C++23 WebSocket 传输库，支持 TLS 1.3 加密，提供 POSIX Socket 和 DPDK 两种后端，面向超低延迟场景。

**核心能力**：
- 无锁 SPSC 队列（BoundedQueue / EvictingQueue）
- 完整 TLS 1.3 握手 + AEAD 热路径加密/解密
- WebSocket 协议（帧编解码、掩码、分片重组、UTF-8 校验）
- 通用 Transport 层（TCP 工厂 → TLS → WS 升级 → TX/RX 工作线程）
- DPDK 用户态 TCP 状态机
- 高精度性能测量（TSC 校准、HDR 直方图、RTT 统计）

**架构概要**：eph-base → eph-utils → eph-containers → eph-net → eph-dpdk

**当前成熟度**：功能基本可用 → 接近生产就绪

**已有测试覆盖**：15 个测试文件，480 个测试用例全部通过

## 推进记录

### 缺口 5: TX 批量消费优化
- 需求：TX loop 使用 try_consume_n 代替逐条 try_consume
- 方案：替换 while(try_consume) 循环为 try_consume_n 调用
- 改动：`eph-net/include/eph/net/transport.hpp`
- 测试：74 个通过
- 提交：`dac44bf`

### 缺口 2: DNS 超时保护
- 需求：getaddrinfo 可能无限阻塞，需要超时保护
- 方案：std::async + wait_for 包装 getaddrinfo 调用
- 改动：`eph-net/include/eph/net/socket_transport.hpp`
- 测试：19 个通过
- 提交：`a4b3607`

### 缺口 4+9: 连接耗时统计 + 连接元数据
- 需求：添加 DNS/TCP 建连延迟记录和 local_port 查询
- 方案：steady_clock 计时 + getsockname 查询本地端口
- 改动：`socket_transport.hpp`, `test_socket_transport.cpp`
- 测试：19 个通过（含新增断言）
- 提交：`149782c`

### 缺口 11: Plain WebSocket (ws://) 支持
- 需求：支持不使用 TLS 的 WebSocket 连接
- 方案：TransportConfig 增加 use_tls 标志，条件跳过 TLS 阶段
- 改动：`transport.hpp`, `transport_types.hpp`, `socket_transport.hpp`
- 测试：480 个通过
- 提交：`92551ac`
