## 内容摘要
讨论围绕 benchmarks/ 和 tests/ 目录的平铺结构是否需要改为按模块（containers/utils/net/dpdk）拆分子目录展开。核心争议在于：手动依赖映射表的维护成本 vs 目录重组的迁移代价。R6 提出的关键论点——当前 fallback 到默认依赖（eph-containers）可能导致"静默编译通过但链接了错误依赖"——说服了最初反对改动的 R2 和 R4。最终全员收敛于"按模块拆子目录 + 根 xmake.lua 单循环自动发现"方案，共享头文件保留在根目录。

## 第 1 轮

**【极简主义者 R2 | 反对过度拆分】**
论点：当前结构实际上没那么糟。14 个 benchmark 文件和 20 个 test 文件，用 `os.files()` 自动发现，依赖通过两个小 map 表声明——总共不到 40 行。真正的"不优雅"只是 `bench_deps`、`dpdk_tests`、`net_tests` 这三个手动映射表。如果改成按模块拆子目录，增加了 4 层目录结构，每个文件变长了路径，但省下的只是那三个映射表。代价和收益不匹配。

**【维护性倡导者 R6 | 按模块拆分子目录】**
论点：手动映射表是定时炸弹。每新增一个测试文件，必须记住去 xmake.lua 的映射表里加一行，否则它默认挂到 `eph-containers` 上。按模块拆子目录，目录本身就是依赖声明，xmake.lua 可以用单循环 + module map 实现零手动映射。

**【第一性原理者 R5 | 质疑问题本质】**
论点："不优雅"的定义是什么？可能是：(1) 映射表需要手动维护；(2) benchmark 和 test 的依赖逻辑散落在 xmake.lua 中间；(3) 文件命名约定承担了太多语义。如果核心痛点只是 (1)，解法不一定是拆目录。如果是 (2)，可以用 `includes()` 分文件。

**【实用主义者 R4 | 维持现状，微调即可】**
论点：4 个模块，34 个文件。映射表维护成本极低。为此重组目录结构，要改 `.gitignore`、IDE 配置、CI 脚本等。如果嫌 xmake.lua 长，把 benchmark/test 的 target 定义 `includes()` 到子文件就够了——零文件移动。

**【系统思维者 R12 | 考虑扩展性】**
论点：当前 4 个模块已经产生了三个映射表。不同模块的测试可能需要不同的编译选项（如 dpdk 需要 `-march=native`），目前被 if 分支隐含处理，未来会变成嵌套的 if-else 森林。

## 最终方案

### 核心决策
按模块拆分 `tests/` 和 `benchmarks/` 为子目录，用目录结构替代手动依赖映射表，在根 xmake.lua 中用单循环自动发现和配置。

**xmake.lua 测试部分：**
```lua
local test_deps = {
    containers = {"eph-containers"},
    utils      = {"eph-utils"},
    net        = {"eph-net"},
    dpdk       = {"eph-dpdk"},
}

for dir, deps in pairs(test_deps) do
    for _, file in ipairs(os.files("tests/" .. dir .. "/**.cpp")) do
        target(path.basename(file))
            set_kind("binary")
            set_group("tests")
            set_default(false)
            add_files(file)
            add_includedirs("tests")
            for _, dep in ipairs(deps) do
                add_deps(dep)
            end
            add_packages("gtest")
            add_defines("SPDLOG_NO_EXCEPTIONS")
    end
end
```

**xmake.lua 基准部分：**
```lua
local bench_deps = {
    containers = {"eph-containers"},
    utils      = {"eph-utils"},
    net        = {"eph-net"},
    dpdk       = {"eph-dpdk"},
}

for dir, deps in pairs(bench_deps) do
    for _, file in ipairs(os.files("benchmarks/" .. dir .. "/**.cpp")) do
        target(path.basename(file))
            set_kind("binary")
            set_group("benchmarks")
            set_default(false)
            add_files(file)
            add_includedirs("benchmarks")
            for _, dep in ipairs(deps) do
                add_deps(dep)
            end
            add_packages("benchmark")
            if dir ~= "dpdk" then
                add_packages("tabulate")
            end
    end
end
```

### 已解决的分歧
- **是否值得改** → R6 的"静默 fallback 默认依赖"论点说服了全员
- **是否每个子目录需要独立 xmake.lua** → 不需要，单循环方案更简洁
- **共享头文件放哪** → 保留在根目录，通过 `add_includedirs()` 引用
