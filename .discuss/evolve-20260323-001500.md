## Project Profile

**Position**: ephemeral (eph) -- C++23 header-only ultra-low-latency WebSocket/TLS library for financial exchange market data
**Core capabilities**:
  - Zero-overhead WebSocket (RFC 6455) + TLS 1.3 over POSIX sockets or DPDK kernel-bypass
  - SPSC lock-free/wait-free queues (BoundedQueue / EvictingQueue)
  - Hardware TSC timing, CPU affinity pinning, hugepage memory
  - Concept-based compile-time polymorphism, zero runtime overhead
  - FIX/ITCH financial protocol parsers
**Architecture**: 4-layer modules (utils -> containers -> net/dpdk), concept-driven pluggable TCP backends
**Maturity**: Feature-complete, approaching production-ready
**Test coverage**: 180+ tests across 20 test files (post-evolve)
