## Project Profile

**Position**: Ultra-low-latency C++23 header-only network library for financial data ingestion (WebSocket/TLS over POSIX sockets or DPDK kernel-bypass)

**Core Capabilities**:
- Zero-cost TcpTransport concept abstraction (Socket + DPDK backends)
- TLS 1.3 direct AEAD encryption (~148ns/record)
- WebSocket RFC 6455 with batch mask key cache (~6ns frame encode)
- Lock-free SPSC queues (BoundedQueue + EvictingQueue)
- HDR Histogram, TSC timers, CPU topology utilities
- ITCH and FIX protocol parsers

**Architecture**: 4-layer header-only modules (utils → containers → net → dpdk)

**Current Maturity**: Feature-rich, approaching production-ready

**Test Coverage**: Comprehensive — 136 histogram tests, 60 recorder tests, extensive transport/container/protocol tests
