## Implementation Record

### Gap 1: ThreadStats data race (relaxed atomics)
- **Requirement**: Eliminate UB from cross-thread read/write of ThreadStats fields
- **Approach**: Replace plain `uint64_t` with `std::atomic<uint64_t>`, use `fetch_add(relaxed)` for writes and `.load(relaxed)` for reads. Zero overhead on x86_64 (identical machine code).
- **Files**: transport_types.hpp, transport.hpp
- **Tests**: All 493 existing tests pass unchanged
- **Commit**: 8e63fe6

### Gap 2: Cross-field config validation warnings
- **Requirement**: Detect contradictory settings (verify_peer without TLS, pong_timeout >= ping_interval)
- **Approach**: New `TransportConfig::warnings()` method returning advisory messages. Called from `Transport::create()` with WARN-level logging.
- **Files**: transport_types.hpp, transport.hpp, test_transport_types.cpp (+5 tests)
- **Tests**: 5 new tests covering all warning conditions
- **Commit**: 8e63fe6

### Gap 3: Queue high-watermark tracking
- **Requirement**: Track peak queue occupancy for diagnosing transient backpressure
- **Approach**: `std::atomic<size_t>` with relaxed CAS loop, updated on enqueue/deliver. Exposed via `tx_queue_hwm()`/`rx_queue_hwm()` and in TransportStats dump/JSON.
- **Files**: transport.hpp, transport_types.hpp
- **Tests**: All existing tests pass
- **Commit**: 8e63fe6

### Gap 4: TransportConfig::to_json() missing extra_headers
- **Requirement**: Include all config fields in JSON serialization
- **Approach**: Add `extra_headers` field to `to_json()` format string with proper JSON escaping.
- **Files**: transport_types.hpp, test_transport_types.cpp (+1 test)
- **Tests**: 1 new test verifying extra_headers appears in JSON
- **Commit**: 8e63fe6
