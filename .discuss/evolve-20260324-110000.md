**核心能力**：
  - Unified TLS 1.3 + WebSocket API across kernel socket and DPDK backends
  - Lock-free SPSC queues with cache-line optimization
  - Zero-copy data paths with ~139-164ns end-to-end latencies
  - Pluggable message framers (WebSocket, ITCH/MoldUDP64, FIX)
**架构概要**：6 header-only modules: utils → containers → net → dpdk/itch/fix
