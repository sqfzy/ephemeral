## Project Profile

**Position**: Ultra-low-latency C++23 header-only networking library for financial market data ingestion (WebSocket/TLS over POSIX sockets or DPDK kernel-bypass).

**Core Capabilities**:
- Generic WebSocket transport with TLS 1.3 (pluggable TCP backends via concepts)
- Lock-free SPSC queues (bounded + evicting) with cache-line alignment
- NASDAQ ITCH 5.0 zero-copy parser with tag-type dispatch
- FIX 4.4 zero-copy parser/builder with repeating group support
- DPDK user-space TCP state machine for kernel-bypass
- Hardware TSC timer, HDR histogram, CPU affinity utilities

**Architecture**: 6 layered modules (utils -> containers -> net -> dpdk/itch/fix), all header-only, compile-time polymorphic via C++20 concepts.

**Maturity Before**: Near production-ready
**Test Coverage**: 32 test files, 16 benchmark files

## Implementation Record

### Gap 1: Transport::send() null data UB
- **Requirement**: Prevent nullptr dereference in UTF-8 validation when data is null
- **Solution**: Added early `if (len > 0 && !data) return kNullData` guard to send(), send_text(), send_for(), send_text_for()
- **Changed**: eph-net/include/eph/net/transport.hpp
- **Tests**: 2 new tests (SendTextNullDataReturnsNullData, SendForNullDataReturnsNullData)

### Gap 2: Transport::recv_peek()
- **Requirement**: Inspect next RX message without consuming (for message-type routing)
- **Solution**: 3 overloads: recv_peek(callback(data,len)), recv_peek(callback(data,len,opcode)), peek_recv_msg()
- **Changed**: eph-net/include/eph/net/transport.hpp
- **Tests**: 3 new tests (RecvPeekReturnsMessageWithoutConsuming, RecvPeekEmptyReturnsFalse, PeekRecvMsgReturnsCopiedMessage)

### Gap 3: std::formatter<TransportConfig>
- **Requirement**: Enable std::format("{}", config) for consistent logging
- **Solution**: Added formatter specialization with compact one-line format
- **Changed**: eph-net/include/eph/net/transport_types.hpp

### Gap 4: EvictingQueueBytes stats()
- **Requirement**: Monitor discard rate and queue health
- **Solution**: Added Stats struct with dump()/to_json() and stats() method
- **Changed**: eph-containers/include/eph/containers/evicting_queue_bytes.hpp
- **Tests**: 1 new test (stats_reflects_push_and_consume)

### Gap 5: Transport::reconnect_now()
- **Requirement**: Application-driven forced reconnect for stale data detection
- **Solution**: Atomic flag checked in RX loop, triggers do_reconnect()
- **Changed**: eph-net/include/eph/net/transport.hpp
- **Tests**: 3 new tests (ReconnectNowTriggersReconnection, ReconnectNowReturnsFalseWhenDisabled, ReconnectNowReturnsFalseWhenStopped)
