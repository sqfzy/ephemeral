## Project Profile

**Purpose**: C++23 header-only ultra-low-latency networking library for HFT/market data
**Core capabilities**:
  - Unified WebSocket/TLS transport (`Transport<TcpImpl>` concept-based static polymorphism)
  - TLS 1.3 AEAD fast-path encryption (~150ns/record)
  - SPSC lock-free queues (BoundedQueue/EvictingQueue + Bytes variants)
  - Zero-copy ITCH 5.0 / FIX protocol parsers
  - Nanosecond HDR histogram + TSC timing
**Architecture**: 6 independent modules (utils, containers, net, dpdk, itch, fix) decoupled via C++20 concepts
**Maturity**: Near production-ready — comprehensive API, 126+ tests, 15 benchmark suites, CI with sanitizers
**Test coverage**: All modules have unit tests including boundary conditions and error paths
