## Project Profile

**Position**: Ultra-low-latency header-only C++23 WebSocket transport library with TLS 1.3 AEAD and dual backend (socket + DPDK).

**Core Capabilities**:
  - Lock-free SPSC queues (BoundedQueue + EvictingQueue) with zero-copy visitor pattern
  - TLS 1.3 AES-256-GCM encryption via aws-lc single-call AEAD API (~148ns/64B)
  - RFC 6455 WebSocket protocol (frame codec, masking, fragmentation reassembly, UTF-8 validation)
  - Dual-thread TX/RX data plane with batch coalesced TCP writes
  - Automatic reconnection (exponential backoff + jitter), ping/pong RTT measurement
  - Socket and DPDK kernel-bypass TCP backends via TcpTransport concept

**Architecture**: eph-utils (TSC, CPU, hugepage) -> eph-containers (SPSC queues) -> eph-net (WS transport) -> eph-dpdk (optional)

**Maturity**: Feature-rich, approaching production-ready. 550+ tests, comprehensive benchmarks.
