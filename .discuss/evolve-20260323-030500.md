**核心能力**：
  - 统一的 Socket/DPDK 双后端抽象（C++20 concepts, 零开销多态）
  - 无锁 SPSC 队列（BoundedQueue / EvictingQueue）
  - WebSocket + TLS 1.3 端到端加密（AEAD 直接调用）
  - ITCH 5.0 / FIX 协议零拷贝解析与构建
  - 硬件级计时（TSC）、CPU 亲和性、大页分配
**架构概要**：分层设计 — eph-utils → eph-containers → eph-net/eph-dpdk → eph-itch/eph-fix
