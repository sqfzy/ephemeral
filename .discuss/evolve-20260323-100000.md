## 项目画像

**定位**：面向超低延迟场景（金融行情接入）的 C++23 header-only 网络库
**核心能力**：
  - 统一 TcpTransport concept（POSIX socket / DPDK 零开销切换）
  - TLS 1.3 热路径 AEAD（绕过 SSL_write/read，~150ns/record 节省）
  - RFC 6455 WebSocket（CSPRNG 掩码池，~2ns/key）
  - SPSC 无锁队列（BoundedQueue / EvictingQueue）
  - ITCH 5.0 / FIX tag-value 协议解析器 + 可插拔 MessageFramer
  - 纳秒级性能记录（HdrHistogram + TSC）
**架构概要**：四层模块 eph-utils → eph-containers → eph-net → eph-dpdk，加 eph-itch / eph-fix 协议层
**当前成熟度**：功能基本可用
**已有测试覆盖**：700+ 测试用例，覆盖所有模块

## 推进记录

### 缺口 1: FIX parser 字段溢出错误处理
- 需求：超过 kMaxFields 时返回明确错误而非静默截断
- 方案：新增 ParseError::kFieldOverflow 枚举值，parse() 中 push() 失败时返回此错误
- 改动：eph-fix/include/eph/fix/parser.hpp, tests/fix/test_fix.cpp
- 测试：1 个新增（parse_field_overflow_returns_error）
- 提交：90b8779

### 缺口 2: FIX framer checksum 校验
- 需求：decode() 应验证 checksum 值，与 parser 一致
- 方案：在 decode() 中计算 sum-of-bytes mod 256 并与声明值比较
- 改动：eph-fix/include/eph/fix/framer.hpp, tests/fix/test_fix.cpp
- 测试：1 个新增（decode_checksum_mismatch）
- 提交：90b8779

### 缺口 3: connector.hpp 代码去重
- 需求：消除两个 connect() 重载之间的 ~50 行重复代码
- 方案：提取 detail::prepare_connection() 函数，返回 ConnectionSetup 结构体
- 改动：eph-dpdk/include/eph/dpdk/connector.hpp
- 测试：已有 connector 测试覆盖
- 提交：90b8779

### 缺口 4: ITCH/FIX 协议解析 benchmark
- 需求：建立 ITCH/FIX 解析性能基线
- 方案：新增 bench_itch_parse（6 个 benchmark）和 bench_fix_parse（8 个 benchmark）
- 改动：benchmarks/itch/bench_itch_parse.cpp, benchmarks/fix/bench_fix_parse.cpp, xmake.lua
- 提交：90b8779
