## Analysis

No performance regression from the evolve changes. This is expected since:
- `get_timestamp()`, `get_bool()`, `dispatch()` are new methods that don't affect existing parse paths
- `trim()` is a new utility function, not called by any existing code path
- `has_overflow()` is a simple bool accessor

The FIX and ITCH parsers maintain their sub-microsecond latencies.
