## 项目画像

**定位**：高性能、低延迟 C++23 header-only WebSocket/TLS 1.3 通信库，支持 POSIX socket 和 DPDK 内核旁路两种 TCP 后端。

**核心能力**：
- 无锁 SPSC 队列（BoundedQueue + EvictingQueue，含字节流变体）
- TLS 1.3 握手 + AEAD 记录层加密（aws-lc/BoringSSL）
- WebSocket RFC 6455 协议（帧编解码、分片重组、UTF-8 校验）
- 高层 Transport 抽象（泛型 TCP 后端，自动重连，ping/pong RTT 测量）
- DPDK 用户态 TCP 栈（最小实现，面向超低延迟场景）
- 工具集：CPU 拓扑、大页内存、TSC 计时、HDR 直方图

**架构概要**：4 个 header-only 模块（utils → containers → net → dpdk），通过 C++23 concept 抽象 TCP 后端。Transport 使用独立 TX/RX 线程 + SPSC 队列实现无锁数据平面。

**当前成熟度**：功能基本可用 → 接近生产就绪

**已有测试覆盖**：13 个测试文件，464+ 测试用例，覆盖容器、网络协议、Transport、工具集。
