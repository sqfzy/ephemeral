# Design Report

## 概况
- 时间：2026-03-23 10:26:00
- 耗时：约 16 分
- 需求：补充 6 个 example（minimal_ws_client, production_client, spsc_queue_demo, perf_tuning_basics, dpdk_quickstart, framer_showcase）
- 讨论轮数：3 轮
- 参与角色：用户代言人(R7)、极简主义者(R2)、性能狂热者(R3)、维护性倡导者(R6)、测试驱动者(R13)

## 需求边界

**In scope**：6 个新 example + xmake.lua 注册
**Out of scope**：不修改现有 ws_echo_client.cpp，不添加测试，不添加新库 API

## 候选方案

- A: 全部需要真实连接 → 否决（framer 需要 3 个不同服务器）
- B: 按需隔离（网络 example 连真实服务器，独立 example 无网络依赖）→ 采纳
- C: 最小化所有 → 否决（违背 production_client 定位）

## 讨论过程

### 主要争议
1. framer_showcase 是否连接真实服务器 → 不连接，聚焦 API
2. 延迟测量方式 → TSC::now() 差值（比 measure_tsc 更直观）
3. CPU 亲和性 → 可选 CLI flag（不强制 root）
4. DPDK 守卫 → #ifdef EPH_HAS_DPDK（与 ws_echo_client 一致）

### 收敛路径
方案 B 在第 1 轮即获全票支持，后续 2 轮聚焦实现细节。

### 关键设计决策
| 决策 | 选择 | 否决项 | 理由 |
|------|------|--------|------|
| 独立性 | 按需隔离 | 全连接/最小化 | 维护成本低，不依赖外部服务器 |
| 延迟测量 | TSC::now() 差值 | measure_tsc() | 更直观易懂 |
| CPU 亲和性 | 可选 CLI flag | 硬编码 | 不强制 root |
| Framer 展示 | 独立 encode/decode | 连接服务器 | 聚焦 API |
| DPDK 守卫 | #ifdef | 独立编译 | 一致性 |
