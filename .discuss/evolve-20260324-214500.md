## Project Profile

**Position**: Ultra-low-latency WebSocket/TLS transport library for HFT, dual backends (POSIX + DPDK kernel-bypass)
**Core capabilities**:
  - Generic `Transport<TcpImpl, Framer>` with compile-time backend selection via C++20 concepts
  - TLS 1.3 data-path optimization (direct AEAD, ~150ns bypass of SSL_write/read)
  - SPSC lock-free queues (BoundedQueue + EvictingQueue) with cache-line separation
  - ITCH 5.0 and FIX protocol zero-copy parsers
  - TSC-based nanosecond timing, CPU affinity, hugepage allocation
  - HDR histogram recording for latency distribution analysis
**Architecture**: Header-only C++23, concept-based polymorphism, cache-line aware layout
**Current maturity**: Feature mostly complete, approaching production readiness
**Test coverage**: 964 tests across all modules (utils, containers, net, itch, fix, dpdk)
