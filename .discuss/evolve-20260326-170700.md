## 推进记录

### 1. Binance 非标准 WS GUID (85456c8)
- 发现 http.hpp 使用 `C5AB0DC85B11` 而非 RFC 6455 的 `5AB5FC6D97BA`
- 尝试修复 → Binance 连接失败 → 手动验证 Binance 确实使用非标准 GUID
- 结论：不是 bug，是 Binance 的行为。添加文档注释

### 2. DPDK 端口 TIME_WAIT 修复 (1c05ef9)
- 所有 DPDK benchmarks/examples 默认 local_port=32768（固定）
- 连续运行时 TIME_WAIT 阻塞后续连接
- 改为 local_port=0（随机 49152-65535）

### 3. Mock server 多连接 (8d8712d)
- 原来 accept() 只调用一次，每次测试需重启 mock
- 改为 accept 循环，断开后自动等待新连接
- 加 1s accept 超时以响应 SIGINT 和 --duration

### 4. 启用 -Wall -Wextra (308977d + f1f135c + 9e399b4 + bd0def5 + 501dacf)
- 全局启用 set_warnings("all", "extra")
- 修复 ~20 个警告：nodiscard、unused-result、multi-line comment、missing-field-initializers
- 2 个残留 GCC 误报（///注释 -Wcomment），无实际风险

### 5. Benchmark 输出一致化 (f1f135c)
- 4 个 market benchmarks 统一输出 `Avg frames/record: X.X (N frames, M records)`

### 6. make_twophase_filter 测试 (c1e3bf6)
- 两个重载完全无测试覆盖 → 新增 7 个测试
- 覆盖：latest-per-symbol、zero-hash、single-frame、all-same-symbol、empty-span、many-symbols

### 7. 文档更新 (aa0c71c)

### 8. Mock server batch-jitter (64a761f)
