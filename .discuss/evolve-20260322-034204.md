## 项目画像

**定位**：高性能 C++23 header-only WebSocket 库，面向金融市场数据等超低延迟场景，支持 DPDK 内核旁路和标准 socket 双后端

**核心能力**：
- DPDK 零拷贝 WebSocket over TLS 1.3 通信（E2E TX 164ns–441ns）
- Lock-free SPSC 队列（EvictingQueue / BoundedQueue）
- 通用 Transport 模板，C++20 concept 可插拔 TCP 后端
- TLS 1.3 直接 AEAD 加解密

**架构概要**：eph-base → eph-utils → eph-containers → eph-net → eph-dpdk

**当前成熟度**：功能基本可用 → 接近生产就绪

**已有测试覆盖**：305 个测试（本次新增 11 个），覆盖协议编解码、加密、队列、工具类

## 推进记录

### 缺口 2: WebSocket 编码器 payload_len 边界校验
- 需求：RFC 6455 要求 64-bit payload length MSB=0，控制帧 ≤125 字节
- 方案：encode_frame_header 添加前置校验，返回 0 表示无效；新增 kMaxPayloadLen / kMaxControlPayloadLen 常量和 is_valid_payload_len() helper
- 改动：websocket.hpp, test_websocket.cpp
- 测试：6 个新增
- 提交：3bc8828

### 缺口 3&4: SocketTransport setsockopt/getsockopt 返回值检查
- 需求：所有系统调用返回值必须检查
- 方案：每个 setsockopt 加 if 检查 + WARN 日志；getsockopt(SO_ERROR) 失败返回 error
- 改动：socket_transport.hpp
- 测试：10 个已有测试全部通过
- 提交：000ed6f

### 缺口 5: TLS BIO 超时日志
- 需求：poll_rx_blocking 超时时无诊断信息
- 方案：超时路径添加 WARN 日志
- 改动：tls_session.hpp
- 提交：071313a

### 缺口 6: BoundedQueue 阻塞批量写
- 需求：try_push_n/try_produce_n 有 try_ 版本但无阻塞版本
- 方案：push_n(span) 和 produce_n(n, visitor) 自旋等待
- 改动：bounded_queue.hpp, test_bounded_queue.cpp
- 测试：5 个新增（含跨线程阻塞验证）
- 提交：87c24b5

### 缺口 8: Transport is_connected()
- 需求：用户需要简单判断连接是否活跃
- 方案：基于 state() 的便捷方法
- 改动：transport.hpp
- 提交：c5d3cc5

### 缺口 9: SocketTransport TRACE 日志
- 需求：send/recv 成功路径无可观测性
- 方案：TRACE 级别日志（release 编译期消除）
- 改动：socket_transport.hpp
- 提交：7df78d8
