## 推进记录

### 缺口 1: ConcurrentRecorder export methods
- 需求：多线程记录器缺少文件导出能力，与单线程 Recorder API 不对称
- 方案：合并所有线程数据后使用与 Recorder 相同的输出格式；JSON 额外包含线程数元数据
- 改动：eph-utils/include/eph/utils/recorder.hpp
- 测试：编译通过，800+ 测试全部通过
- 提交：4890d92

### 缺口 2: DnsConfig::dump()
- 需求：所有 Config 类型都有 dump() 用于日志，DnsConfig 缺失
- 方案：添加多行格式化输出，包含 nameserver IP:port 和 timeout
- 改动：eph-dpdk/include/eph/dpdk/dns.hpp
- 测试：编译通过，800+ 测试全部通过
- 提交：4890d92
