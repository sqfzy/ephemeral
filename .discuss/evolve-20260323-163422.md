## Implementation Record

### Gap #5: format_double() rounding carry (FIXED)
- **Bug**: When `frac * multiplier + 0.5` rounds up to `10^precision` (e.g., 0.995 at precision=2 -> frac_int=100), `format_uint(100)` writes 3 digits into 2-digit precision, producing `"0.100"` instead of `"1.00"`.
- **Impact**: Incorrect price fields in outbound FIX messages — a real-money bug.
- **Fix**: Detect carry (`frac_int >= frac_limit`), rewrite integer part with `int_part + 1`, reset frac_int to 0.
- **Files changed**: `eph-fix/include/eph/fix/builder.hpp`
- **Tests added**: 5 rounding carry tests + 3 reset/reuse stress tests
- **Commit**: `01ada46`
