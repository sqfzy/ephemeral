## 项目画像

**定位**：C++23 header-only 超低延迟 WebSocket 通信库，面向金融交易场景
**核心能力**：
  - 零开销传输抽象（concept-driven，socket/DPDK 可互换）
  - TLS 1.3 数据面旁路（EVP_AEAD 单次调用）
  - Lock-free SPSC 队列（BoundedQueue + EvictingQueue）
  - WebSocket/ITCH 5.0/FIX 协议栈
  - 硬件 TSC 计时、CPU 亲和性、HugePages
**架构概要**：6 个 header-only 库模块，eph-utils/containers 基础层 → eph-net 传输核心 → eph-itch/fix 协议层 → eph-dpdk 内核旁路后端
**当前成熟度**：功能基本可用 → 接近生产就绪

## 推进记录

### 缺口 1: FIX builder has_tag()
- 需求：检测 MessageBuilder 中是否已写入某个 tag，防止重复 tag 违反 FIX 规范
- 方案：扫描已写入 body 的 "tag=value\x01" 边界匹配 tag 编号，O(field_count) 复杂度
- 改动：eph-fix/include/eph/fix/builder.hpp, tests/fix/test_fix.cpp
- 测试：7 个新增
- 提交：40fb693

### 缺口 2: FIX/ITCH ParserStats dump/to_json/formatter
- 需求：ParserStats 缺少人类可读输出、JSON 监控输出、std::format 支持
- 方案：复用 eph-net 的 dump/to_json/formatter 模式，包含错误诊断信息
- 改动：eph-fix/include/eph/fix/parser.hpp, eph-itch/include/eph/itch/parser.hpp, 两个测试文件
- 测试：8 个新增
- 提交：f6f3876

### 缺口 3: TransportStats delta operator
- 需求：长期运行进程需要窗口化指标（如最近 10 秒的 PPS）
- 方案：operator-() 计算两个快照的差值，counter 字段相减，metadata 取较新快照
- 改动：eph-net/include/eph/net/transport_types.hpp, tests/net/test_transport_types.cpp
- 测试：4 个新增
- 提交：b107818

### 缺口 4: BoundedQueue peek()
- 需求：SPSC 消费端需要预检查消息类型/路由逻辑而不消费
- 方案：try_peek() 读取 head 元素但不推进 head 指针，两个重载（引用 + optional）
- 改动：eph-containers/include/eph/containers/bounded_queue.hpp, tests/containers/test_bounded_queue.cpp
- 测试：5 个新增
- 提交：0f254b9

### 缺口 5: version.hpp API 扩展
- 需求：运行时版本查询和下游代码版本门控
- 方案：kVersionFull ("ephemeral/1.0.0") + consteval version_at_least()
- 改动：eph-utils/include/eph/version.hpp, tests/utils/test_version.cpp
- 测试：2 个新增
- 提交：5e70d36
