## Project Profile

**Positioning**: Ultra-low-latency C++23 header-only network library for financial exchange WebSocket + TLS 1.3 communication.

**Core capabilities**:
- Dual-backend transport (POSIX sockets / DPDK kernel-bypass)
- Lock-free SPSC queues (BoundedQueue, EvictingQueue)
- ITCH 5.0 and FIX 4.4+ protocol parsers (zero-copy)
- TSC timing, HDR histograms, CPU affinity utilities
- Pluggable MessageFramer concept

**Architecture**: eph-utils -> eph-containers -> eph-net -> eph-dpdk, with eph-itch/eph-fix add-ons.

**Maturity before**: Functional, approaching production-ready
**Test coverage before**: 811 tests across 20 suites
