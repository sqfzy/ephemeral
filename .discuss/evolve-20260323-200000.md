## Implementation Log

### Gap 1: FIX `get_timestamp()`
- **Requirement**: Parse "YYYYMMDD-HH:MM:SS.sss" (21-char) and "YYYYMMDD-HH:MM:SS" (17-char) back to epoch nanoseconds
- **Approach**: Inverse Howard Hinnant algorithm (same as builder), pure integer arithmetic, no allocations
- **Changes**: `eph-fix/include/eph/fix/parser.hpp` (MessageView::get_timestamp)
- **Tests**: 7 new (epoch zero, round-trip, no-millis, leap year, invalid format, missing tag, wrong length)
- **Commit**: `f700228`

### Gap 2: ITCH `trim()`
- **Requirement**: Trim trailing spaces from fixed-width ITCH string fields
- **Approach**: `string_view::find_last_not_of(' ')` — zero-copy, O(n)
- **Changes**: `eph-itch/include/eph/itch/messages.hpp` (trim function)
- **Tests**: 8 new (basic trim, no spaces, all spaces, empty, single char, single space, interior spaces, end-to-end with stock accessor)
- **Commit**: `69e1253`

### Gap 3: FIX `dispatch()`
- **Requirement**: Type-safe message routing via tag-type overloads, mirroring ITCH dispatch pattern
- **Approach**: msg:: tag structs + switch on MsgType char, same pattern as eph::itch::dispatch
- **Changes**: `eph-fix/include/eph/fix/parser.hpp` (msg namespace + dispatch template)
- **Tests**: 6 new (NewOrderSingle, ExecutionReport, Heartbeat, unknown type, return value forwarding, all 12 known types)
- **Commit**: `eafe693`

### Gap 4: FIX `get_bool()`/`set_bool()`
- **Requirement**: Typed accessors for FIX Y/N boolean fields
- **Approach**: `get_bool()` delegates to `get_char()`, `set_bool()` writes "Y"/"N"
- **Changes**: `parser.hpp` (get_bool), `builder.hpp` (set_bool)
- **Tests**: 7 new (Y→true, N→false, invalid char, multi-char, missing tag, round-trip true, round-trip false)
- **Commit**: `062dcbd`

### Gap 5: `MessageBuilder::has_overflow()`
- **Requirement**: Query overflow state mid-build without waiting for finish()
- **Approach**: Expose existing `overflow_` flag as public const accessor
- **Changes**: `builder.hpp` (has_overflow method)
- **Tests**: 3 new (initially false, true after overflow, false after reset)
- **Commit**: `4bf1ce9`
