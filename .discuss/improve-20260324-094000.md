### 关键决策与教训
1. **C++ 模板嵌套类型的 formatter 限制**：`BoundedQueue<T,N>::Stats` 等嵌套在模板类中的类型无法做 `std::formatter` 偏特化（编译器无法从嵌套类型推导外层模板参数）。解决方案有两种：(a) 提取 Stats 到 namespace 级别（改变 API 表面），(b) 保持现状，用 dump()/to_json() 替代。选择 (b) 因为 API 变更代价大于收益。
