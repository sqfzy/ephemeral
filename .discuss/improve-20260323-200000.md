# Improve Report

## Scope
Code review and quality improvements for the 5 evolve commits (FIX/ITCH API additions).

## Issues Found & Fixed

### Critical (Fixed)
1. **Pre-epoch timestamp UB** — `get_timestamp()` cast negative `int64_t` to `uint64_t`, producing garbage for dates before 1970-01-01. Now returns `std::nullopt`.
2. **Invalid date acceptance** — `get_timestamp()` accepted impossible dates like Feb 31, Feb 29 on non-leap years. Added per-month day validation with leap year handling.

### Suggestions Applied
3. **ITCH `trim()` made `constexpr`** — `std::string_view::find_last_not_of` is `constexpr` in C++23; aligned with project's compile-time preference.

### Documented (Not Fixed — Low Priority)
4. FIX `dispatch()` only examines first char of MsgType — correct for FIX 4.4, would need extension for FIX 5.0 multi-char MsgType.
5. `set_timestamp()` year > 9999 wraps silently — extremely unlikely in practice.
