## 推进记录

### 缺口 1: TSC::init() 线程安全
- 需求：防止多线程并发调用 init() 导致数据竞争
- 方案：使用 std::call_once + std::once_flag 包装，将原 init() 逻辑移至私有 do_init_()
- 改动：eph-utils/include/eph/utils/time.hpp
- 测试：新增 concurrent_init_is_safe 测试（8线程并发调用）

### 缺口 5: EvictingQueue try_peek_latest_for()
- 需求：与 try_consume_latest_for() 对称的超时 peek API
- 方案：在通用模板和 Capacity=1 特化中分别添加三个重载（visitor/T&/optional）
- 改动：evicting_queue.hpp（通用 + 特化）、evicting_queue_bytes.hpp（bytes 包装层）
- 测试：新增 6 个 TYPED_TEST + 1 个独立测试（含延迟写入唤醒场景）

### 缺口 6: 编译期 static_assert 加固
- 需求：更早暴露模板参数错误
- 改动：bounded_queue.hpp（Capacity >= 2）、builder.hpp（kHeaderReserve >= 28）
