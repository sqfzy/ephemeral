## Phase 3: Retrospective

### Lesson
When adding a new variant to an enum, always grep for all switch statements on that enum across the project before committing. The /evolve commit added `DecodeError::kInvalidOpcode` and updated websocket.hpp and test_websocket.cpp, but missed ws_framer.hpp which also switches on `DecodeError`.

### Decision
- **Options**: Add explicit case vs rely on fallthrough to "unreachable" default
- **Choice**: Explicit case — maintains exhaustive switch pattern, eliminates -Wswitch warning
- **Retrospect**: Correct choice; explicit is always better for enum switches
