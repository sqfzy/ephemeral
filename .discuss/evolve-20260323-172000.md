## Project Profile

**Position**: C++23 header-only ultra-low-latency network library for financial market data ingestion
**Core Capabilities**:
  - Dual-backend transport (POSIX socket / DPDK kernel-bypass) via zero-overhead concept abstraction
  - TLS 1.3 with hot-path AEAD (bypasses SSL_write/SSL_read)
  - WebSocket RFC 6455, FIX protocol, ITCH 5.0 parsing
  - Lock-free SPSC queues (bounded + evicting)
  - TSC-based nanosecond timing, HDR histograms
**Architecture**: 6 modular header-only packages (utils -> containers -> net -> dpdk/fix/itch)
**Prior Maturity**: Functional, approaching production-ready
**Test Coverage**: 136 tests passing across containers, utils, net, FIX, ITCH
