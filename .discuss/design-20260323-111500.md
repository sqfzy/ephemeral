# Design Report

## 概况
- 时间：2026-03-23 11:15
- 需求：为 DPDK 实现用户态 DNS 解析器
- 讨论轮数：3（低复杂度，全票方案 A）
- 参与角色：R2(极简)、R4(实用)、R12(系统)
- 提交：eab66fe

## 需求边界
- In scope: UDP 头构造、DNS A 记录查询/解析、blocking resolve、超时重试、connector 集成
- Out of scope: AAAA/CNAME、DNS over TCP、DNS 缓存、异步 DNS、/etc/resolv.conf 自动解析

## 最终设计
- 新增 `dns.hpp`：与 `arp.hpp` 同级，同模式（build packet → tx_burst → poll → parse）
- UDP 头 + DNS 报文编解码：QNAME encoding、DNS header、A record parsing with pointer compression
- connector.hpp 集成：DNS-resolving connect() 先尝试 kernel DNS，失败后自动 Platform→ARP→DPDK DNS
- ConnectorOptions 新增 `dns` 字段（DnsConfig，默认 8.8.8.8）

## 实现概况
- 新增文件：dns.hpp (~400 行)、test_dns.cpp (~280 行)
- 修改文件：connector.hpp（include + DNS fallback 逻辑 + ConnectorOptions.dns 字段）
- 测试用例：20 个（QNAME 编码、DNS 查询构建、响应解析、name pointer、config、resolve 快速路径）

## 关键设计决策
| 决策 | 选择 | 否决项 | 理由 |
|------|------|--------|------|
| 文件组织 | 独立 dns.hpp | 内联到 connector | 与 arp.hpp 一致，职责单一 |
| UDP checksum | 跳过（设 0） | 计算 | IPv4 UDP checksum 可选，减少复杂度 |
| DNS fallback | 自动（kernel 失败后 DPDK） | 手动选择 | 对用户透明，无需额外配置 |
| nameserver | 默认 8.8.8.8，可配置 | 解析 resolv.conf | 保守，避免文件 I/O 依赖 |
