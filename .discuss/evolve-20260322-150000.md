## 项目画像

**定位**：高性能 C++23 header-only 低延迟 WebSocket/TLS 1.3 通信库，支持 POSIX socket 和 DPDK 双后端。

**核心能力**：
- Lock-free SPSC BoundedQueue + SeqLock EvictingQueue（及字节流包装器）
- 完整 WebSocket 协议栈（帧编解码、HTTP Upgrade、控制帧处理、分帧重组）
- TLS 1.3 record-level AEAD 加解密（热路径独立于 OpenSSL）
- 泛型 Transport 流水线（App→SPSC→TX Thread→WS Frame→TLS→TCP）
- DPDK 用户态 TCP（三次握手、数据收发、乱序重组）
- 工具层：TSC 计时、大页分配、CPU 亲和性、HdrHistogram

**架构概要**：5 个 header-only 模块（base→utils→containers→net→dpdk），层级依赖

**当前成熟度**：功能基本可用 → 接近生产就绪

**已有测试覆盖**：17 个测试文件，397 个测试用例全部通过

## 推进记录

### 缺口 1: BoundedQueue try_consume_n 批量零拷贝消费
- 需求：与 try_produce_n(n, F(T&, size_t)) 对称的批量消费 visitor
- 方案：best-effort 语义，返回实际消费数量
- 改动：bounded_queue.hpp, test_bounded_queue.cpp
- 测试：10 个新测试用例
- 提交：b6b0f4d

### 缺口 2+3: Transport SendError enum + send_for()
- 需求：类型安全错误枚举替代裸 errno + 带超时发送
- 方案：SendError enum class + send_for() 使用 BoundedQueue::try_produce_for
- 改动：transport.hpp, test_tcp_concept.cpp, socket_wss_client.cpp, ws_echo_client.cpp
- 测试：3 个新测试用例
- 提交：f0ffbba

### 缺口 4: BoundedQueueBytes 批量操作
- 需求：批量入队 (push_n/push_n_wts) + 批量零拷贝消费 (try_consume_n/try_consume_n_wts)
- 方案：委托给底层 BoundedQueue 的 try_produce_n/try_consume_n
- 改动：bounded_queue_bytes.hpp, test_bounded_queue_bytes.cpp
- 测试：7 个新测试用例
- 提交：5c8aebd

### 缺口 5: EvictingQueueBytes 批量写入
- 需求：push_n/push_n_wts 批量 wait-free 写入
- 方案：委托给底层 EvictingQueue::produce_n，预校验所有 payload 大小
- 改动：evicting_queue_bytes.hpp, test_evicting_queue_bytes.cpp
- 测试：4 个新测试用例
- 提交：eba64aa
