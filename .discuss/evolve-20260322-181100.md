## Project Profile

**Purpose**: High-performance C++23 WebSocket client library for ultra-low-latency trading systems
**Core capabilities**:
  - Dual transport backends: POSIX socket (universal) + DPDK (kernel-bypass, sub-microsecond)
  - Full RFC 6455 WebSocket + TLS 1.3 encryption
  - Zero-overhead abstraction via C++23 concepts + template monomorphization
  - Cache-line aligned SPSC lock-free queues with batch operations
  - Nanosecond-precision latency measurement (HDR Histogram)
  - Automatic reconnection with exponential backoff + jitter
**Architecture**: 4-layer modular -- eph-utils -> eph-containers -> eph-net -> eph-dpdk
**Prior maturity**: Functionally complete, approaching production-ready
**Prior test coverage**: 18 test files covering all modules EXCEPT the core Transport class (2087 lines, zero tests)
