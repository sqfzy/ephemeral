## 项目画像

**定位**：超低延迟 WebSocket (WSS) 客户端库，支持 DPDK 内核旁路和传统 Socket 后端，面向高频交易和实时数据场景。

**核心能力**：
- TLS 1.3 握手 + AEAD 热路径加解密 (sub-µs latency)
- WebSocket RFC 6455 全合规（掩码、分片、ping/pong、优雅关闭）
- 无锁 SPSC 队列 + CPU 绑核线程模型（TX/RX 分离）
- 指数退避自动重连 + 可配置回调
- HDR 直方图 RTT 测量、每 opcode 统计
- TcpTransport concept 抽象，可插拔后端

**架构概要**：eph-base → eph-utils → eph-containers → eph-net → eph-dpdk，均为 header-only C++23

**当前成熟度**：功能基本可用 → 接近生产就绪

**已有测试覆盖**：18+ 测试套件覆盖队列、WS 编解码、TLS 记录层、HTTP 升级、TCP concept、config 校验。

## 推进记录

### 缺口 2: HTTP header injection prevention
- 需求：ws_subprotocol 字段直接拼入 HTTP Upgrade 请求，含 CR/LF 可注入任意 HTTP 头
- 方案：在 TransportConfig::validate() 中增加 CR/LF 字符检查
- 改动：transport_types.hpp, test_transport_types.cpp
- 测试：新增 1 个测试 (SubprotocolWithCRLFFailsHeaderInjection)
- 提交：ce79439

### 缺口 15+6: TransportStats remote_ip + JSON dump
- 需求：监控系统集成需要 JSON 格式输出；运维需要连接 IP 上下文
- 方案：TransportStats 增加 remote_ip 字段 + to_json() 方法
- 改动：transport_types.hpp, transport.hpp, test_transport_types.cpp
- 测试：新增 4 个测试 (DumpIncludesRemoteIp, DumpShowsUnknownForEmptyRemoteIp, ToJsonProducesValidFormat, ToJsonHandlesEmptyRemoteIp)
- 提交：0e5041a

### 缺口 1: IPv6 dual-stack support
- 需求：SocketTransport 硬编码 AF_INET，无法连接 IPv6-only 服务端
- 方案：getaddrinfo 改用 AF_UNSPEC + AI_ADDRCONFIG；resolve_ip 支持 AF_INET6
- 改动：socket_transport.hpp
- 测试：19 个现有测试全部通过 (test_socket_transport)
- 提交：79d809b
