## 项目画像

**定位**：C++23 header-only 高性能 WebSocket/TLS 网络库，支持 POSIX socket 和 DPDK 双后端
**核心能力**：
  - 双后端 TCP 传输（POSIX socket + DPDK kernel bypass）
  - TLS 1.3 (aws-lc EVP_AEAD direct)
  - WebSocket RFC 6455（二进制/文本、ping/pong、close 握手）
  - SPSC 无锁队列（BoundedQueue + EvictingQueue）
  - HDR 直方图延迟统计（Recorder + ConcurrentRecorder）
  - ITCH 5.0 / FIX 协议支持
**架构概要**：分层模块 utils → containers → net → dpdk → itch/fix，C++20 concepts 编译时多态
**当前成熟度**：接近生产就绪
**已有测试覆盖**：全模块覆盖，边界条件+错误路径+状态机验证

## 推进记录

### 缺口 1: TLS SNI failure → hard error when verify_peer=true
- 需求：SNI 设置失败 + verify_peer=true → 返回 error 并释放 SSL/CTX
- 方案：区分 verify_peer 状态，true 时 return unexpected，false 时保留 WARN
- 改动：eph-net/include/eph/net/tls_session.hpp
- 测试：已有 TLS 测试覆盖
- 提交：c5a0a89

### 缺口 2: TlsConfig observability
