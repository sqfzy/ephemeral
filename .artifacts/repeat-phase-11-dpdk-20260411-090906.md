### Mid-run root-cause fix

The legacy uppercase `bench.conf` keys (`EAL_CORES=0,1 # DPDK EAL lcores`) carry trailing inline comments that `ScenarioConfig::load_globals` preserves verbatim. First DPDK run failed EAL init with "unexpected character in lcore list". Root-cause fix added a `strip_inline_comment` helper in `bench::load_dpdk_env` that rtrims whitespace and cuts at the first `#`, matching the legacy `BenchConfig` parser's behavior for the same keys.
