# Design Report

## 概况
- 时间：2026-03-28 04:04:52
- 耗时：约 21 分钟
- 需求：Phase 1 (v1.1) — 错误处理统一、Framer 概念增强、隐式依赖显式化、type alias 补齐
- 讨论轮数：5 轮
- 参与角色：极简主义者(R2)、性能狂热者(R3)、维护性倡导者(R6)、测试驱动者(R13)、架构师(R14)
- 提交：待用户确认

## 需求边界

**In scope**：
1. 错误处理模式统一（ErrorEnum concept + ErrorEnumFormatter）
2. Framer decode 从静态方法改为实例方法
3. 提取 eph-core 模块（概念 + 类型 + LengthPrefixFramer）
4. transport_types.hpp 拆分（error types → eph-core，config/filter → eph-net）
5. Type alias 体系化

**Out of scope**：
- Context 模板参数（Phase 2 additive）
- TcpTransport concept 错误类型变更（v2.0）
- 统一 ErrorCode 枚举（否决）

## 候选方案

- **方案 A**：最小侵入——decode 改实例方法 + eph-core 提取
- **方案 B**：Context 模板参数 + 错误统一枚举 + eph-core
- **方案 C**：CRTP 基类 + 全新错误层级

## 讨论过程

### 主要争议
Context 参数是否 Phase 1 加入（R3 主张现在做避免二次 breaking change vs R2 主张 YAGNI）

### 收敛路径
R14 提出 additive concept 方案（Phase 2 加 ContextFramer concept，不是 breaking change）化解了分歧。
全员收敛到 **方案 A+**：A 的基础 + R6 的错误模式统一 + eph-core 完善。

### 关键设计决策

| 决策 | 选择 | 否决项 | 理由 |
|------|------|--------|------|
| Context 参数 | Phase 2 additive | Phase 1 加入 | ContextFramer concept 可 additive 方式加入 |
| 错误统一方式 | ErrorEnum concept + 模式统一 | 统一 ErrorCode 枚举 | 各模块错误语义不同 |
| Framer 架构 | Concept（改实例方法） | CRTP 基类 | 保持 concept-driven 风格 |
| eph-core 内容 | 概念+类型+LengthPrefixFramer | 不含 LPF / 含 TransportConfig | aws-lc 传递依赖问题 |
| transport_types.hpp | 拆分 + 原文件保留为聚合头 | 直接删除原文件 | 零 breaking include change |
| Namespace | 保留 eph::net | 迁移到 eph::core | 避免大规模 namespace 迁移 |

## 最终设计

### 新增文件
```
eph-core/include/eph/core/
├── error_traits.hpp           — ErrorEnum concept + ErrorEnumFormatter
├── tcp_concept.hpp            — TcpState + TcpTransport concept
├── framer_concept.hpp         — FrameError + DecodedFrame + MessageFramer concept (decode=instance)
├── transport_errors.hpp       — SendError + ConnectionError + ConnectionErrorInfo
├── length_prefix_framer.hpp   — 2-byte BE length-prefix framer
└── detail/
    └── json_escape.hpp        — JSON string escaping utility
```

### 修改文件
- `xmake.lua` — 新增 eph-core target，eph-fix/eph-itch/eph-dpdk 改用 add_deps("eph-core")
- `eph-net/include/eph/net/{tcp_concept,framer_concept,length_prefix_framer,detail/json_escape}.hpp` — 变为 forwarding headers
- `eph-net/include/eph/net/transport_types.hpp` — error types 提取，include eph-core
- `eph-net/include/eph/net/ws_framer.hpp` — decode 改实例方法
- `eph-net/include/eph/net/raw_framer.hpp` — decode 改实例方法
- `eph-net/include/eph/net/socket_transport.hpp` — 新增 type aliases
- `eph-net/include/eph/net/transport.hpp` — Framer::decode → rx_framer_.decode，新增 rx_framer_ 成员
- `eph-fix/include/eph/fix/framer.hpp` — decode 改实例方法，include 改 eph-core
- `eph-itch/include/eph/itch/framer.hpp` — include 改 eph-core
- `eph-dpdk/include/eph/dpdk/types.hpp` — 新增 type aliases
- 测试文件: `tests/{net/test_framer,fix/test_fix,itch/test_itch}.cpp` — 适配实例方法调用
- 基准文件: `benchmarks/{net/bench_rx_pipeline,itch/bench_itch_parse,fix/bench_fix_parse}.cpp`
- 示例: `examples/framer_showcase.cpp`

## 实现概况
