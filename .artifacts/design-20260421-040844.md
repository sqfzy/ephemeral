- 时间：2026-04-21 开始，耗时单会话内完成

## 需求边界

### In scope（本次实现）

- SYN-ACK TCP options 解析 + effective MSS 协商
- `DpdkTcpStream` 自动 src_port 分配（需传入 `DpdkPoller&`）
- `~TcpSession()` best-effort RST
- TCP keepalive（default off，配置驱动、pull-model tick）
- ICMP Frag Needed (Type 3 Code 4) PMTU 反馈
- 7 项新 StreamMetric + `publish_metrics` 集成
- 66 行状态机 conformance 测试

### Out of scope（保持 plan 既定边界）

- Listen / Accept（P1）
- Window Scaling（P1）
- 拥塞控制 / SACK / TCP Timestamps（永不做）
- IPv6 / 多 RX queue / RSS

## 关键设计决策

| 决策 | 选择 | 否决项 | 理由 |
|------|------|--------|------|
| MSS 协商存储 | `TcpSession::effective_mss_` 单值 | 维护 peer_mss / icmp_mss 独立字段 | 任何降级都 `std::min` 进去，读侧零分支 |
| 自动 src_port API | `create(cfg, poller)` 重载 | 给 StreamConfig 加 `DpdkPoller*` 字段 | 签名层显式依赖 + 默认 `create(cfg)` 保持严格 validate |
| Destructor RST | `if state_ != Closed && pool_ != nullptr` | 无条件 `reset()` | null-pool 测试路径必须不 crash |
| Keepalive 触发 | caller-driven `tick_keepalive(now_tsc)` | poller 内置定时器 | 与 `flush_pending_ack` 一致 pull-model；零线程 |
| ICMP dispatch | `DpdkPoller::set_icmp_callback(cb, user)` 单回调 | 每-entry tick hook + 扩展 DpdkPollable concept | 单流场景（HFT 主流）够用；多流让用户自建 dispatcher |
| Stats → Metric 桥 | `metric()` switch lazy-read `sess_.tcp_stats()` | 并行 `inc_<M>()` 原子计数 | 单一事实源 + 热路径零额外 atomic |
| Conformance test 层 | legacy `FakeTcpMbuf` + `pool=nullptr` | DPDK e2e NIC-bound | 纯状态机测无 NIC 依赖、运行快 |
| CLOSING + FIN 行为 | pin 当前实现（→ TIME_WAIT） | 修为 RFC 793 严格（→ 保持 Closing） | plan 只做 P0 状态机安全网，不 re-interpret RFC |

## 后续建议

1. **DPDK E2E bench 回归**（P1）：确认 NIC-B 空闲后运行 `sudo benchmarks/latency/lat tcp --dpdk` 对比基线，检查 keepalive tick（poll_once_ 内一次 `TSC::now()` + 条件跳）与 metric() switch 的 ≤ 1% 延迟门槛。
2. **`test_dpdk_e2e.cpp` 编译失败**（既存，非本次引入）：on_message 回调签名与 `DpdkTcpStream::OnMessage` 不一致，应独立 commit 修复。
3. **多流 ICMP dispatcher**（P2）：当前 `set_icmp_callback` 单回调对多流不完备，可 promote 为 per-entry hook on `DpdkPollable`，与本次设计兼容。
4. **Keepalive tick for Poller-driven 多流**（P2）：当前只有 `poll_once_` 集成，多流用户需手动调 `stream.session().tick_keepalive()`，应在 `DpdkPoller::poll()` 中加 per-entry tick 回调。
5. 文档：`summary.md` / `eph-net-dpdk/summary.md` / `CLAUDE.md` "Available public surface" 补充本次新增 API（effective_mss / keepalive / on_icmp_frag_needed / 新 StreamMetric）。
